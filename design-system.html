Design System

Reference for Artifacts Recordings. This page is not linked from the site navigation and is marked noindex — it is reachable by URL only. Every sample below uses the live style.css, so what you see here is what the site renders.

#0a0a0a

#666666

Strictly monochrome. --fg carries all primary text and solid fills, --mid all secondary and supporting text, and --border every hairline rule. Colour is never used to convey meaning on its own.

Rockwell and Helvetica Neue are the brand faces. Libre Baskerville and Inter are the closest web-available stand-ins and are what actually load; the real faces sit first in each fallback stack so they are used where installed.

Media frames

.poster-wrapmax 320px · natural ratio

.release-mediamax 260px · 1:1 · cover

Posters keep their natural proportions and set their container's height. Square release media is fixed at 1:1 and cropped with object-fit: cover. Where two posters crossfade, the second is absolutely positioned over the first so the container never changes size.

Carousel tile

01

.tile-face — square, --fg ground, media cropped to fill and overscaled 2% to hide subpixel seams while the ring scales it. Numbered fallback shows when a slot has no media. On desktop the ring is an elliptical path with depth faked by scale and stacking order, so tiles never rotate or skew; below 680px it flattens to a scroll-snapping strip.

Layout & Spacing

Content width   max-width: 1100px, centred
Gutter   2rem desktop · 1.25rem below 680px
Breakpoint   single breakpoint at 680px
Carousel stage   max-width 1280px · height 360px
Block grid   5fr / 6fr media-left · 6fr / 5fr media-right · 4rem gap
Header height   64px, sticky, z-index 1000
Base size   16px · body weight 300

Alternating blocks mirror their grid so media sides swap down the page. Grid children carry min-width: 0 to stop content forcing a track wider than its share. Full-bleed rules span the viewport while their content stays within the 1100px measure.
